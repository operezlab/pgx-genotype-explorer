# Pharmacogenomics Genotype Explorer

Teaching tool for the Temple University School of Pharmacy pharmacogenomics course.
Students load their own 23andMe raw data file and compare their genotypes with
CPIC allele definitions for drug-response genes.

- Runs entirely in the web browser: the genome file is never uploaded or stored.
- For education only; not for clinical decisions.
